Single Phase Half-Wave Controlled Rectifier — R Load, R-L Load & R-L-E Load
SCR-based controlled rectification · Firing angle α · Extinction angle β · Back-EMF E · 50 Hz system
i Introduction

A Single Phase Half Wave Controlled Rectifier is a rectifier circuit which converts AC input into DC output only for the positive half cycle of the AC input supply. The word "controlled" means that we can change the starting point of load current by controlling the firing angle of the SCR; the SCR turns ON at a certain point in time when it is forward biased. A Single Phase Half Wave Controlled Rectifier circuit consists of an SCR (thyristor), an AC voltage source and a load. The load may be purely resistive (R), inductive (R-L), or include a back-EMF source (R-L-E).

Key points for controlled rectifier operation:

1) The necessary condition for turn-ON of an SCR is that it should be forward biased and a gate signal must be applied. An SCR will only turn ON when it is forward biased and gated.

2) An SCR will turn off only when the current through it falls below the holding current and a reverse voltage is applied for a duration greater than the SCR turn-off time.
1 Single Phase Half Wave Controlled Rectifier with Resistive (R) Load

The circuit consists of a thyristor T, AC source Vs = Vm sin ωt, and a purely resistive load R. Here V0 = load output voltage, i0 = load current and VT = voltage across the thyristor T. It is assumed that the peak supply voltage never exceeds the forward and reverse-blocking ratings of the thyristor.

Fig. 1: Single Phase Half Wave Controlled Rectifier with R Load

During the positive half cycle, the thyristor anode is positive w.r.t. its cathode; until gated, it blocks forward current. When fired at angle α, the full supply voltage is applied to the load. With a purely resistive load, the current waveform is identical to the voltage waveform. At the zero crossing (ωt = π), the thyristor turns off by natural commutation. By varying α, the output voltage is controlled. During the negative half cycle the thyristor blocks all current.

Analysis — Average load voltage:

Eq. 1 — Vdc (R Load)
\[V_{dc} = \frac{1}{2\pi}\left[\int_{\alpha}^{\pi} V_m\,\sin\omega t\;d(\omega t)\right] = \frac{V_m}{2\pi}(1+\cos\alpha)\]
Eq. 2 — Maximum Vdc (α = 0)
\[V_{dc\,max} = \frac{V_m}{\pi}\]
Eq. 3 — Average current (R Load)
\[I_{dc} = \frac{V_{dc}}{R} = \frac{V_m}{2\pi R}(1+\cos\alpha)\]
Eq. 4 — RMS load voltage
\[V_{L\,rms} = \frac{V_m}{2\sqrt{\pi}}\left(\pi-\alpha+\tfrac{1}{2}\sin 2\alpha\right)^{1/2}\]
Eq. 5 — Vrms at α = 0
\[V_{L\,rms} = \frac{V_m}{2}\]
Eq. 6 — RMS load current
\[I_{L\,rms} = \frac{V_{L\,rms}}{R} = \frac{V_m}{2R\sqrt{\pi}}\left(\pi-\alpha+\tfrac{1}{2}\sin 2\alpha\right)^{1/2}\]
Eq. 7 — Average output power
\[P_{dc} = V_{dc}\cdot I_{dc} = \frac{V_m^2}{4\pi^2 R}(1+\cos\alpha)^2\]

2 Single Phase Half Wave Controlled Rectifier with R-L Load
Fig. 1 — R-L Load Circuit Diagram
Fig. 1: Single Phase Half Wave Controlled Rectifier with R-L Load

The circuit consists of a thyristor T, source Vs and an R-L load. When the thyristor is fired at ωt = α, load voltage equal to the source voltage appears instantaneously across the load. However, because the load is inductive, the current cannot change instantaneously — at ωt = α the current is still zero and rises gradually.

At ωt = π, the load voltage reduces to zero. However, due to inductance L, the load current is not yet zero — the stored magnetic energy forces the current to continue flowing. The thyristor therefore stays ON even though the supply is now negative, conducting until ωt = β. The angle β (extinction angle) is where io = 0 and the thyristor turns off by natural commutation. The conduction angle is (β − α).

The circuit turn-off time is tc = (2π − β)/ω seconds. This must exceed the thyristor turn-off time to avoid commutation failure.

Fig. 4 — R-L Load Waveforms
Fig. 4: Waveforms — input voltage, output voltage, load current, firing pulse VT

Voltage equation (KVL):

KVL — R-L Load
\[V_m\sin\omega t = Ri_o + L\,\frac{di_o}{dt}\]

The load current io consists of a steady-state component is and a transient component it:

Steady-state component
\[i_s = \frac{V_m}{\sqrt{R^2+X_L^2}}\sin(\omega t-\phi)\]
Transient component
\[i_t = A\,e^{-(R/L)t}\]
Eq. 8 — General solution
\[i_o = \frac{V_m}{Z}\sin(\omega t-\phi) + A\,e^{-(R/L)t}\]

Applying boundary condition io = 0 at ωt = α (i.e. t = α/ω), the constant A is:

\[A = -\frac{V_m}{Z}\sin(\alpha-\phi)\,e^{\,R\alpha/L\omega}\]
Eq. 9 — Instantaneous current (R-L Load)
\[i_o = \frac{V_m}{Z}\left[\sin(\omega t-\phi) - \sin(\alpha-\phi)\,\exp\!\left\{-\frac{R}{\omega L}(\omega t-\alpha)\right\}\right]\]
Eq. 10 — Average output voltage
\[V_o = \frac{V_m}{2\pi}(\cos\alpha - \cos\beta)\]
Average load current
\[I_o = \frac{V_m}{2\pi R}(\cos\alpha - \cos\beta)\]
Eq. 11 — RMS load voltage
\[V_{or} = \frac{V_m}{2\sqrt{\pi}}\sqrt{(\beta-\alpha)-\tfrac{1}{2}(\sin 2\beta - \sin 2\alpha)}\]
3 Single Phase Half Wave Controlled Rectifier with R-L-E Load
Fig. 1 — R-L-E Load Circuit Diagram
Fig. 1: Single Phase Half Wave Controlled Rectifier with RLE Load

A counter-EMF E in the load may be due to a battery or a DC motor. The SCR can only turn ON when the instantaneous supply voltage Vmsin ωt exceeds E. The minimum firing angle θ1 is obtained from:

Eq. 12 — Minimum firing angle (αmin)
\[\theta_1 = \sin^{-1}\!\left(\frac{E}{V_m}\right)\]

If the thyristor is fired at α < θ1, then E > Vs, the SCR is reverse biased and will not turn ON. The maximum firing angle is θ2 = π − θ1. During intervals when io = 0, the load voltage vo = E. When io > 0, vo follows vs. The KVL equation during conduction is:

Eq. 13 — KVL for R-L-E Load
\[V_m\sin\omega t = Ri_o + L\,\frac{di_o}{dt} + E\]
Fig. 4 — R-L-E Load Waveforms
Fig. 4: Waveforms — input voltage, output voltage, load current, gate pulse VT, thyristor voltage

The solution is the sum of steady-state components (is1 due to Vmsinωt, is2 due to E) and a transient component it:

Due to AC source alone
\[i_{s1} = \frac{V_m}{Z}\sin(\omega t-\phi)\]
Due to back-EMF E alone
\[i_{s2} = -\frac{E}{R}\]

Applying io = 0 at ωt = α gives the constant A:

\[A = \left[\frac{E}{R} - \frac{V_m}{Z}\sin(\alpha-\phi)\right]e^{\,R\alpha/L\omega}\]
Eq. 14 — Instantaneous current (R-L-E Load)
\[i_o = \frac{V_m}{Z}\!\left[\sin(\omega t-\phi)-\sin(\alpha-\phi)\exp\!\left\{-\frac{R}{\omega L}(\omega t-\alpha)\right\}\right] - \frac{E}{R}\!\left[1-\exp\!\left\{-\frac{R}{\omega L}(\omega t-\alpha)\right\}\right]\]

Valid for α ≤ ωt ≤ β. The extinction angle β depends on E, α, and the impedance angle φ.

Eq. 15 — Average load current Io
\[I_o = \frac{1}{2\pi R}\Big[V_m(\cos\alpha-\cos\beta) - E(\beta-\alpha)\Big]\]
Eq. 16 — Average load voltage Vo
\[V_o = E\!\left(1-\frac{\gamma}{2\pi}\right) + \frac{V_m}{\pi}\sin\!\left(\alpha+\frac{\gamma}{2}\right)\sin\!\left(\frac{\gamma}{2}\right), \quad \gamma = \beta-\alpha\]

For zero inductance (L = 0), the extinction angle β = π − θ1 and γ = π − θ1 − α:

Eq. 17 — Io for L = 0
\[I_o = \frac{1}{2\pi R}\Big[V_m(\cos\alpha+\cos\theta_1) - E(\pi-\theta_1-\alpha)\Big]\]
Eq. 18 — RMS current for L = 0
\[I_{or} = \left[\frac{1}{2\pi R^2}\int_\alpha^{\pi-\alpha}(V_m\sin\omega t - E)^2\,d(\omega t)\right]^{1/2}\]
Eq. 19 — Power delivered to load
\[P = I_{or}^2 R + I_o E\]
Supply power factor
\[\text{PF} = \frac{I_{or}^2 R + I_o E}{V_s\,I_{or}}\]
4 Advantages, Disadvantages & Applications
Advantages
  1. Simple circuit, easy to construct.
  2. Low cost, fewer components.
  3. Economical at initial stage.
Disadvantages
  1. Low transformer utilization factor.
  2. Low output voltage.
  3. DC saturation of transformer core causing harmonics and hysteresis losses.
  4. Power delivered only in one half cycle.
  5. High ripple factor — requires heavy filtering.
Applications
  1. AM radio demodulation
  2. Pulse-generation circuits
  3. Signal demodulation
  4. Voltage multiplier circuits
