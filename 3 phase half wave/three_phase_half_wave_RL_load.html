🔬What is this experiment?

Welcome to the Three Phase Half Wave Controlled Rectifier experiment with RL Load.

A Three-Phase Half Wave Controlled Rectifier converts three-phase alternating current (AC) into direct current (DC) using three SCRs (Silicon Controlled Rectifiers) — one for each phase. It is called a half-wave rectifier because only the positive half of each phase is utilised.

With an RL load, the inductor L stores energy and smooths the current waveform — the load current becomes more continuous and less pulsating than with a pure R load. This is the typical condition in real industrial loads such as DC motors and electromagnets.

⚡How does it work?

The three AC phases — Phase A, Phase B, and Phase C — are each shifted 120° apart. At any instant, the SCR connected to the phase with the highest instantaneous voltage is triggered to conduct. Conduction begins at the firing angle α, measured from the natural commutation point (30° ahead of each phase peak). The conducting SCR turns off automatically (natural commutation) when another SCR is fired with a higher voltage.

By varying α from 0° to 150°, the average output voltage Vdc can be smoothly controlled from its maximum value down to zero.

🎯Learning objectives

After completing this experiment you will understand: the effect of inductance on load current continuity, how RL load extends the conduction angle beyond that of R load, why load current remains smoother for higher L/R ratios, how to analyse Vdc, Vrms, Idc, Irms, Form Factor, and Ripple Factor for RL load.

🔌Circuit Components

The circuit consists of the following components. Click each to learn its role:

⚡ AC Voltage Sources (Va, Vb, Vc)

Three sinusoidal voltage sources, each 120° apart. They provide the three-phase input supply. Pin 1 = Va+, Pin 3 = Vb+, Pin 5 = Vc+, Pin 2/47 = Neutral.

🔴 SCR-A, SCR-B, SCR-C (Thyristors)

Silicon Controlled Rectifiers — the main switching devices. Each SCR has an Anode, Cathode, and Gate. They conduct only when forward-biased AND a gate pulse is applied. They turn off by natural commutation when a higher-phase SCR fires.

📡 Gate Pulse Generators (GP-A, GP-B, GP-C)

Generate trigger pulses at firing angle α for each SCR. GP-A fires SCR-A at 30°+α, GP-B fires SCR-B at 150°+α, and GP-C fires SCR-C at 270°+α in each cycle.

🔋 RL Load (R + L in series)

A series R-L load. R dissipates power; L stores magnetic energy and smooths current. The inductor keeps current flowing even when source voltage falls below load voltage, extending the SCR conduction angle beyond that of a pure R load.

🔢 Ammeter (IL)

Measures the load current flowing from the common cathode bus through the resistor and back to the neutral. Connected in series between the cathode bus and the load.

📏 Voltmeters (VINP, VT, VGP, VLOAD)

Multiple voltmeters measure: input AC phase voltage (VINP), voltage across each SCR (VT1/VT2/VT3), gate pulse voltage (VGP-A/B/C), and output load voltage (VLOAD).

🌍 Ground Nodes (GND-A, GND-B, GND-C)

Reference ground points for the gate pulse voltmeter negative terminals. Essential for correct measurement of gate-to-cathode voltage of each SCR.

🔗 Neutral Bus (Pin 47)

The common neutral return path connecting the bottom of the load resistor and all three source neutrals. Completes the DC output loop back to the supply.

📈Output Waveforms

The simulation plots the following waveforms. Understanding each helps you verify circuit operation:

Three-Phase Input Voltages (Va, Vb, Vc) & Output Envelope
Three sinusoids 120° apart. The output voltage follows the upper envelope — at any instant it equals the phase with the highest value, starting from firing angle α.
Load Current Waveform (IL)
For RL load, the inductor smooths the current — it is more continuous than for pure R load. The L/R time constant τ = L/R determines how smooth the current is. Higher L → smoother IL. Ripple frequency = 3 × 50 Hz = 150 Hz.
Gate Pulse Waveforms (GP-A, GP-B, GP-C)
Narrow trigger pulses fired sequentially at α, 120°+α, and 240°+α within each cycle. Each pulse turns ON the corresponding SCR for that phase's conduction interval.
Thyristor Voltage Waveforms (VT1, VT2, VT3)
When an SCR conducts: VT ≈ 0 V (forward drop). When blocking: VT = negative phase-to-phase voltage. Peak reverse voltage VPRV = √3 × Vm ≈ 1.73 × Vm.

📐Effect of Firing Angle α

As α increases from 0° to 150°: the conduction interval per SCR decreases, the output envelope shifts rightward, Vdc reduces proportionally as cos α, and ripple increases. At α = 90°, Vdc = 0. Beyond 90°, the rectifier enters inverter mode (with inductive load only).

📊Simulation Output Parameters

After clicking ▶ Run, the sidebar displays the following calculated values:

Vdc — Average Output Voltage
Vdc = (3√3 · Vm) / (2π) · cos α. Maximum at α=0°: Vdc,max ≈ 0.827 · Vm. This is the useful DC voltage delivered to the load.
Vrms — RMS Output Voltage
Vrms = Vm · √(¼ + (3√3/8π) · cos 2α). Always ≥ Vdc. The extra energy compared to Vdc represents ripple.
Idc and Irms — Load Currents
For R load: Idc = Vdc/R and Irms = Vrms/R. These determine the power dissipated and the thermal rating of the resistor.
Form Factor (FF) and Ripple Factor (RF)
FF = Vrms/Vdc — quality of DC output (ideal = 1). RF = √(FF²−1) — ratio of AC ripple to DC value. Lower RF = smoother output. Three-phase HWR has much lower RF than single-phase.

Load Differential Equation
L · dI/dt + R · I = Vsource(t)
Governs current while an SCR conducts. Solved numerically.
Average Output Voltage (Vdc)
Vdc = (3√3 · Vm) / (2π) · cos α   (ideal, continuous current)
At α=0°: Vdc,max ≈ 0.827 · Vm. Actual Vdc computed numerically.
Load Time Constant
τ = L / R
Higher τ → smoother current. Continuous current when τ is large.
Average Load Current (Idc)
Idc = (1/T) ∫ i(t) dt   (numerical)
Computed by numerical integration of ODE over steady-state cycles.
RMS Load Current (Irms)
Irms = √((1/T) ∫ i²(t) dt)   (numerical)
Determines heating effect; smoother current → lower Irms/Idc ratio.
Form Factor & Ripple Factor
FF = Irms / Idc    RF = √(FF² − 1)
RL load has lower RF than R load for same α — inductor improves DC quality.
Peak Reverse Voltage (PRV)
VPRV = √3 · Vm
Maximum reverse voltage each SCR must withstand (same as R load)
