🔬What is this experiment?

A Single Phase Full Wave Controlled Rectifier with an R-L-E Load simulates a practical DC motor drive. 'E' represents the motor's Back Electromotive Force (EMF).

Because of the back EMF, thyristors can only become forward-biased when the input AC voltage exceeds 'E'. If fired before this, they will not turn on.

⚡Conduction Modes & Back EMF

When the current drops to zero, the output voltage instantly snaps to the level of the Back EMF 'E', rather than zero. This is Discontinuous Conduction Mode (DCM).

If the inductance is high, the current may never drop to zero (CCM), and the voltage waveform will transition directly between the positive and negative AC cycles.

🔌Circuit Components

⚡ AC Voltage Source

Provides the single-phase AC main input supply.

🔴 Thyristor Bridge

Four SCRs. T1 & T4 conduct the positive half, T3 & T2 conduct the negative half.

📡 Gate Pulse Generators

Provide triggers. You can set the firing angle (α) for the primary pair, and the other pair shifts by π.

🔋 Series R-L-E Load

Models a DC motor. Resistor, Inductor, and a Battery (Back EMF) in series.

📈Waveforms & Outputs

Output Voltage & Current
When current extinguishes, output voltage snaps to 'E' instead of 0V.
Thyristor Voltages
Displays the blocking voltage across the SCRs when they are not conducting.
ODE Engine
An internal solver calculates the exact transient current equations frame-by-frame.

  • Vm :Peak value of AC input voltage
  • R, L :Load Resistance (Ω) and Inductance (mH)
  • E :Back EMF / Battery Voltage (V)
  • α :Delay (Firing) Angle
  • β :Extinction Angle (where current hits zero)
  • θ1 :Critical Conduction Angle [sin⁻¹(E/Vm)]
  • CCM :Continuous Conduction Mode
  • DCM :Discontinuous Conduction Mode
  • VDC :Average load voltage
Transient Current Equation (ODE)
L(di/dt) + R·i(t) + E = vrectifier(t)
Solved numerically to determine exact non-sinusoidal motor current.
Output Voltage state (DCM)
vload(t) = E    (when i(t) = 0)
When the current extinguishes, the load voltage is equal to the Back EMF.
Critical Angle (θ₁)
θ₁ = sin⁻¹(E / Vm)
Thyristors cannot conduct before this angle.
Average Output Voltage (General)
Vdc = (Vm/π) [cos(α) − cos(β)]
Valid for both CCM and DCM. Represents average output voltage over conduction interval (α to β).
