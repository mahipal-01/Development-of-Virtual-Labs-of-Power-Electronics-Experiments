Single Phase Full Wave Controlled Rectifier with R Load

Read the quick overview before starting the experiment.

Press Read Aloud to hear this section

🔬What is this experiment?

A Single Phase Full Wave Controlled Rectifier converts alternating current (AC) into direct current (DC) using four Thyristors (SCRs) arranged in a bridge configuration.

Unlike a half-wave rectifier, it uses both the positive and negative halves of the AC cycle, producing two output pulses per cycle. This results in a higher average output voltage and smoother DC output.

⚡How does it work?

During the positive half-cycle, SCRs T1 and T4 are forward-biased and are triggered at the firing angle α. During the negative half-cycle, SCRs T3 and T2 are forward-biased and are triggered at π + α.

By adjusting the firing angle α between 0° and 180°, you can smoothly control the average output voltage delivered to the load.

🔌Circuit Components

⚡ AC Voltage Source

Provides the single-phase AC input supply.

🔴 Thyristor Bridge (T1, T2, T3, T4)

Four SCRs forming a full-wave bridge. T1 & T4 conduct together, and T3 & T2 conduct together.

📡 Gate Pulse Generators (GP1-GP4)

Generate trigger pulses at angle α to turn on the respective SCRs.

🔋 Load Resistor (R)

The resistive load where DC power is consumed.

📈Output Waveforms & Simulation

Output Voltage & Current
You will see two pulses per AC cycle. For a purely resistive load, the current waveform shape is identical to the voltage waveform.
Thyristor Voltages
When conducting, voltage is near zero. When blocking, they withstand the input voltage.
Average Outputs
The average output voltage is calculated as Vm over π times one plus cosine α.

Average Output Voltage (Vdc)
Vdc = (Vm / π) × (1 + cos α)
Integration from α to π for pure R load
RMS Output Voltage (Vrms)
Vrms = (Vm / √2) × √[1 − (α/π) + sin(2α)/(2π)]
Effective heating value across load
Average Load Current (Idc)
Idc = Vdc / R
Ohm's Law for average values
RMS Load Current (Irms)
Irms = Vrms / R
Ohm's Law for RMS values
